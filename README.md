# Rent Calculator - Automated Expense Distribution System

## Project Overview

The Rent Calculator is a Python-based console application created to make sharing monthly household expenses simple and fair. It calculates each roommate's share of rent, electricity, food, and other common expenses, helping save time and reduce calculation errors.

## Features

* Calculates the total electricity bill using units consumed and the rate per unit.
* Divides rent and other shared expenses equally among roommates.
* Allows multiple calculations during a single session.
* Provides a simple and user-friendly text-based interface.
* Reduces errors that can occur during manual calculations.

## Motivation

Sharing expenses in a rented accommodation can sometimes cause confusion or disagreements. This project provides a simple automated solution to divide common expenses fairly, making expense management easier, faster, and more transparent.

## How to Use

1. Run the Python file `rent_calculator.py`.
2. Enter the number of roommates.
3. Enter the rent, food expenses, electricity units, and rate per unit when prompted.
4. View the calculated amount each roommate needs to pay.
5. Choose whether to perform another calculation or exit the program.
